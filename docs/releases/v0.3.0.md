# Sunshine Mono v0.3.0

**Sunshine Mono by SunWorks · 햇살코드**

첫 공식 공개 배포입니다. 한글과 영문이 자연스럽게 이어지는 코딩·터미널용 고정폭 서체입니다.

## 다운로드와 설치

**SunshineMono-0.3.0.zip**을 내려받아 풀고, Regular와 Bold TTF 두 파일을 설치하세요. ZIP에는 WOFF2, 설치 안내, 원천 라이선스, 검증 manifest도 포함됩니다.

설치 후 앱을 다시 열고 **Sunshine Mono**를 선택하세요. 기존 `MM Coding B3`와 별도 패밀리이며, 기존 시안은 자동 제거되지 않습니다. `SHA256SUMS.txt`로 파일 무결성을 확인할 수 있습니다.

## 포함 내용

- Regular 400 / Bold 700의 실제 두 굵기
- 현대 한글 11,172자, 영문 한 칸·한글 두 칸
- 한영 기준 획 두께 조정 및 받침 왼쪽 아래 모서리 라운딩
- 구분하기 쉬운 `0`, `1`, `I`, `l`
- 기존 Iosevka 코딩 리거처와 칸 너비 보존
- 12·13·14·16 및 24·26·28·32 PPEM용 실험 힌팅

## 변경·검증

B3 검증본의 이름을 Sunshine Mono로 변경했습니다. 패밀리명, 전체 이름, PostScript 이름, 제작자, 설명과 버전 메타데이터를 정리했습니다. 윤곽·메트릭·OpenType 기능·TrueType 명령 테이블은 B3와 바이트 단위로 동일함을 검사했습니다.

새 TTF 두 파일에서 FreeType 엄격 모드 180,272회 렌더링과 리거처 15종의 치환·칸 너비를 검사했습니다. macOS CoreText의 새 이름 인식과 실제 Bold 연결, 표본 대체 폰트 없음 및 한영 2:1 너비를 검증했습니다.

## 알려진 한계

이번 공식 배포가 모든 플랫폼의 완성도 보증을 뜻하지는 않습니다. 한글 힌팅은 실험적이며 모든 글자를 수작업으로 조정한 것은 아닙니다. 실제 VS Code·터미널 UI 및 Windows DirectWrite 검증은 아직 완료하지 않았습니다. macOS를 먼저 개선하고 Windows 검증을 이어갈 예정입니다.
