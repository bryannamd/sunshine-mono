# Sunshine Mono v0.5.0 — Fira Code 리거처 적용

Fira Code 6.2의 연산자 문맥 치환과 관련 글리프를 이식했습니다. 획 두께·중심선·폭을 Sunshine Mono에 맞추고 기존 기본 글리프와 한영 고정폭을 보존했습니다.

## 다운로드와 설치

`SunshineMono-0.5.0.zip`에는 Regular·Bold TTF, 웹용 WOFF2, 라이선스, 검증 manifest가 들어 있습니다. 두 TTF를 설치하고 편집기·터미널을 다시 열어 **Sunshine Mono**를 선택하세요. 이전 Sunshine Mono 설치본을 교체합니다.

함께 제공하는 `SHA256SUMS.txt`로 ZIP과 압축 해제한 파일의 무결성을 확인할 수 있습니다.

## 검증

- 두 굵기 합계 FreeType 엄격 렌더링 180,272회 통과
- 현대 한글 11,172자, 영문 550 / 한글 1100 units의 고정폭 유지
- 리거처 치환·칸 너비 및 macOS CoreText 표본 검증
- [변경 상세 및 검증 기록](https://github.com/bryannamd/sunshine-mono/blob/v0.5.0/docs/fira-ligatures.md)

## 알려진 한계

한글 힌팅은 실험적입니다. 실제 편집기·터미널별 사용성, Windows DirectWrite와 장시간 읽기 평가는 별도로 확인해야 합니다.
